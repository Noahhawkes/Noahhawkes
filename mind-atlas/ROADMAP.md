## Milestones

### M1. Public research seed
A coherent atlas with method, source-linked bibliography, provisional journal, and static map. Acceptance: files resolve internally and all sourced external links point to real public documents. Current branch targets this milestone.

### M2. Comprehensive article census
Enumerate repository trees recursively across selected branches; detect articles by type, not filename alone; preserve non-English titles where present; exclude vendor/build trees and generated dependency content; deduplicate copies using hashes while maintaining each original source pointer. Acceptance: published inventory includes repository coverage table and exclusions with reasons.

### M3. Bibliography at research-paper quality
For every eligible paper: author-reviewed attribution, abstract, research question, central claim, evidence level, citation, first known date, latest reviewed revision, and related work. Acceptance: audited publication count and no unresolved broken links.

### M4. Journal crosswalk
Every one of the fifty themes should have traceable supporting and challenging sources or carry an explicit not-yet-supported status. Acceptance: publicly reproducible mapping from every asserted research claim to at least one actual citation; protected personal claims omitted or anonymized.

### M5. Interactive mind map
Implement a filterable static site using a validated JSON graph. Filters should include theme, article type, source state, chronology, and evidence strength. Clicking an edge should display the basis for the claimed connection. Acceptance: no broken source IDs and no unlabeled causal assertions.

### M6. External research evaluation
Separate a literature review and empirical test program from the personal journal. Compare continuity features against baseline retrieval, profiles, and task-management systems. Acceptance: preregistered hypotheses, public evaluation sets where permissible, raw measurements, failure reports, and reproducible scripts.

## Non-goals for this first edition

Do not publish an unreviewed private biography. Do not claim complete GitHub article coverage. Do not certify that a model has a consciousness, human identity, or uninterrupted autonomous capacity. Do not claim live integrations because they are described in design documents. Do not treat a draft pull request as a merged release.

## A useful definition of completion

This project becomes a **comprehensive bibliography** only when the source scope is enumerated and the inclusion and exclusion counts are reconciled. It becomes an **evidence-linked journal** only when each important nonprivate claim has source provenance. It becomes an **interactive atlas** only when readers can browse nodes and relationships and inspect their citations. Until then, each label should describe its actual stage.

## Reader feedback

Corrections should identify the relevant file, heading, and source link. The owner retains final publication authority; well-supported counterevidence should remain visible even when an interpretation is revised.
